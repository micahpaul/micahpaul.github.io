# Class Description: Collab Literature, 2026-2027
Micah Hawkinson<br>
W 12-1p HS Literature<br> 
W 1-2p MS Literature 

### Objectives: 
* Read and enjoy excellent novels 
* Summarize a text 
* Analyze and interpret a text 
* Make and support claims using textual evidence 
* Effectively communicate about literature 

### Expectations:
* Do each week’s reading before class
* Come to class with: 
  - The current book, a notebook, and a pen or pencil 
  - Written responses to the weekly discussion questions
  - A list of quotes (or page numbers) to bring up in class discussion
* Contribute at least one helpful thing to the class discussion each week
* Ask the teacher as early as possible if you have any questions or concerns about class
* Give a brief presentation once per semester about another book you've read outside of class

### Grades:
Semester grades will be based on attendance, meaningful class participation, and the brief presentation.
